## Notes (non-blocking)

1. `Driver::tabs()` and `frames()` scrub only through the process-wide vault (`harness_core::scrub`). Before `Vault::install_global`, tabs() returns the raw typed value from a GET-form URL or title (`note: tabs() before install_global holds the canary: true`). The MCP server installs the vault at start, so this is a precondition and not a leak. It does mean tabs() has no cut-prefix rule (B-613), and a later program's page string relies on core's scrubber alone.
2. Chromium-1248 replaces U+202E, U+200B, U+FEFF and U+2066 with `_` in `Page.downloadWillBegin.suggestedFilename`, for both `filename*=` and `<a download>`. So the live path never hands the driver a Cf character, and `sanitize_name`'s Cf filter is defence in depth, proven by its unit test only.
3. A modal `<dialog>` takes focus itself on `focus()`, so `k#<dialog>=Enter` runs and the Enter goes to the dialog, not to its autofocused Pay button. That meets rule 4: the key reached the classified element only.
4. The reviewer's round-2 Should-fix 1 (closed shadow roots: `deepActive` cannot see into a closed root, so `a === el` holds for the host) is not in this round's rows and was not tested by the tester.
5. 17 `.tmp*` test temp dirs remain under F:/sb-swarm/tmp-driver from earlier sessions. None holds the canary.
