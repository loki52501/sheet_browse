## Notes (non-blocking findings)

- Row 10a's step reports `NoVisibleChange`, but the click inside the frame changed the parent document (`#r` became `hit`). Consequences and the diff read only the step frame's index, so the parent's change is not seen. This belongs with the frame-merging work the coder lists for T-22.
- `Driver::tabs()` returns the canary in the URL after the GET-form echo (`note: tabs() url/title holds the canary: true`). `tabs()` is outside `act` and is not scrubbed by the driver, so the MCP wrapper (or T-22's `tabs()`) must scrub it.
- `Driver::download` returns the saved `PathBuf` with the page's raw name (``[x](#12) ``` n….txt``). It is safe on disk, but it should be escaped before any tool shows it to the model. The Consequence name is already escaped.
- Chrome removes `..\..\` from a quoted `filename="..."` itself. The `filename*=` and `<a download>` forms reach the driver's `safe_name`, which maps them to `_.._name`.
- Testers should use a canary with a `-` in it until `vault_scrub_t05_fix` handles all-alphanumeric canaries (14b (3)).
- Report table header: the tester spec's `| item | command | result | note |`. merge_gate.py reads the `result` column.
