## Notes

1. `tabs()` and `frames()` scrub only through the process-wide vault. Before `Vault::install_global`, tabs() returns a title that echoes a typed value raw (`tabs() before install_global holds the canary: true`). This is the same as T-21 note 1; MCP installs the vault at start.
2. Row 4: `Settled.changed` is 0 in (a) and (b), although `#o` changed while settle waited. A mutation that happens while the Rust side waits for the network, between in-page calls, is not counted. B-4 #8 does not define `changed` precisely, so this is not a fail, but D-620's "the number of DOM mutations the page saw meanwhile" does not hold for it.
3. Row 8: a password field whose value comes only from the `value` attribute (no placeholder, not required, caret at 0) reports `Empty`. This is by design in injected.js `filledNoRead` (H-2: the value is never read) and is not T-22 code. With a placeholder, the same field reports `Filled`.
4. Row 1: the target=_blank click step had `settled: Some(true)` in one run and `settled: None` in another. `settled` was not asserted for it; this is recorded for the reviewer.
5. Row 3c, for scale: open()'s total minus its commit-to-return is 0.25 to 0.53 s in these runs (Target.createTarget with a new window, the runtime install ack, Page.navigate, the commit). That leaves no room under 3.04 s for open() on a page that never settles unless the cap counts from the call.

Verdict: red
