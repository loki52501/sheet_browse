## Failing rows: what is missing, owner

- **4b**: `git commit` reads `--pathspec-from-file[=]<file>` (and `=-` from stdin) as no
  pathspec, so `tree_reaches_runs` is never called. Treat it as reaching runs/, as `git add` and
  `git stash push` already do. Owner: servers rust-coder (T-14b), review-T-14b should-fix 1.
- **6b**: `safeio::check_parent` returns Ok when the parent is missing, and `fs.write` /
  `fs.move` call `create_dir_all(parent)` before any handle check. Check the nearest existing
  ancestor on a handle before creating folders (fs.mkdir, fs.write, fs.move). Owner: servers
  rust-coder (T-14b), review-T-14b should-fix 6.
- **7b**: D-545 makes `.yarnrc` / `.yarnrc.yml` in runs/ Read writes, while the RUNS_CODE
  `--version` exception keeps `yarn --version` Read, so a Read line can run planted JS. Either
  keep dotfiles strict in runs/ for a line that also runs a RUNS_CODE program, or drop the
  `--version` exception when the cwd is in runs/. The yarn chain must then be Delete (this
  test). Owner: servers rust-coder (T-14b), review-T-14b Blocking.
- **7c**: pre-existing, outside T-14b's items. Rustup proxies (`cargo`, `rustc`, ... `--version`)
  read rust-toolchain(.toml) from the cwd and run a `path` toolchain's binary. Toolchain files
  are Read writes in runs/ and Fill outside it. Shown end to end through the shell tool. Needs
  the `--version` exception narrowed for proxies that read cwd config (rustup; also pytest.ini,
  .mvn/jvm.config, global.json per the review). Owner: supreme to file a servers task
  (review-T-14b should-fix 9).
- **T-14 12**: red only from rows 4b, 7b and 7c (tests added here). The other failure was the
  sb-driver flake (B-199), which passed on rerun.
