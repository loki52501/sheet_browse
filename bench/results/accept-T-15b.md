## Failing rows: what is missing, owner

1. **The gh group is the first word, even when it is a flag** (review-T-15b Blocking). Owner: servers rust-coder (srv-cli, `crates/srv-cli/src/gh/mod.rs`). This fails 3 rows: T-15b 2 leading flag, T-15b 3 leading flag, and through them the srv-cli and workspace rows.
   - `needs_aliases` returns false when `argv[0]` starts with `-`. `classify_static` takes `argv[0]` as the group, and `subcommand()` and `repo_host()` read only `argv[1..]`.
   - So `gh --hostname github.com tok` is classed Account with no alias lookup, and gh expands it to `auth token`. `gh --hostname github.com auth token` asks instead of being refused. `gh --repo=o/r run delete 5` and `gh --yes=true repo delete o/r` are Account instead of Delete. `gh --repo=evil.example/o/r pr view 5` is not host-checked.
   - Needed: refuse a gh call whose first word is a flag (except a lone `--help`/`--version`), or skip leading flags the way `subcommand()` does and then classify, look up aliases and check the host from the real group.
   - Proof: `cargo test -j 2 -p srv-cli --test accept_t15b_open item2_open_leading_flag_does_not_skip_the_alias_or_auth_refusal item3_open_leading_flag_does_not_lower_a_delete` turns green.
2. **call re-plans and compares only the class** (review-T-15b should-fix 1; D-591's "why"). Owner: servers rust-coder (`Gh::call`, `gh/mod.rs`). This fails the T-15b 2 equal-class swap row.
   - When the alias changes between classify and call to another command of the same or a lower class, call runs a command nobody classified. The test classified `pr view 5` and ran `issue list 5`.
   - Needed: carry the classify-time plan (argv and domain) into call, or refuse when call's plan differs from it.
   - Proof: `--test accept_t15b_open item2_open_equal_class_alias_swap_is_refused` turns green.
3. **Full srv-cli run and workspace row**: red only because of 1 and 2 (the accept_t15b_open binary). Nothing else fails.
4. **Postgres ledger canary query** (not-run): psql is not installed here. Owner: tester/infra, only if a Postgres check is wanted for srv-cli; srv-cli writes no Postgres rows.
